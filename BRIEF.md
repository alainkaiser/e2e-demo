# Brief

Who this prototype is for and what it shows. Fill it in with the first version and keep it current: every new chat starts here.

## Customer

Sitewerk, for an internal tech talk. Not a customer project.

## Goal

A coffee ordering counter used live to show [e2e](https://e2e.tester.army/docs): locator tests, agent goals that replay, a renamed button, and an explorer that hunts for bugs.

## Users

Someone ordering coffee for the first time. They add drinks, change quantities, try the promo code SITEWERK and place the order.

## Made up

The menu, the prices and the promo code. Nothing is paid and no email is sent. Three mistakes are left in on purpose: the promo code stacks, the quantity can go below zero, and the receipt checkbox is misspelled.

## Brand

Sitewerk Labs tokens from the prototype template: navy, teal and Geist. The wordmark on the page is "Sitewerk".

## Language

English, with prices written as `CHF 9.60`.
